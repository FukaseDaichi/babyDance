# 表情アトラス 画像制作ガイド

[表情・瞬き 設計](../../design.md#表情と瞬き) のアトラス（`FaceEyes.png` / `FaceMouth.png`）のうち、手描き相当のコマを ChatGPT の画像生成で作るための手順と条件。設計書のアトラス規約が正本であり、本書はその制作手順。

## 順番

画像は**デカール殻とコマ 0 のベイクが済んでから**作る。理由は、デカールの UV が「格子平面を頭に shrinkwrap した平面投影」であり、瞳がコマ内のどの位置・大きさに来るかは殻を作るまで決まらないため。先に絵を描くと殻ができた時点で目の位置がずれ、コマ間で目が飛ぶ。

1. `tools/build_face_decals.py` でデカール殻を作り、既存テクスチャをデカール UV にベイクしてコマ 0 を得る
2. コマ 0 を参照画像にして ChatGPT で残りのコマを**編集**で生成する
3. スクリプトで合成・縮小・パディング・アトラス組み立てを行う
4. ランタイム側（`FaceScore` / `FaceDirector`）の実装に進む

## 必要なコマ

| アトラス | ChatGPT で作る | ベイクで作る |
| --- | --- | --- |
| 目 | 1 笑顔、2 驚き、3 得意げ、4 半目、5 閉眼 | 0 通常 |
| 口 | 0 閉じ、1 半開き、2 大きく開く（ベイクを下地に加工） | 加工用の下地 |

## 目アトラスのアスペクト

`FaceEyes` の殻は幅 0.34 × 高さ 0.105（約 3.24:1 の横長）だが、UV は 0..1 の正方形に貼られる。したがって 128×128 のコマは**貼られるときに横に約 3.24 倍引き伸ばされる**。ベイクしたコマ 0 は横に潰れた目になっている。

ChatGPT に潰れた絵を描かせないため、生成はコマ 0 を横 3.24:1 に引き伸ばした画像（例 1024×316）を参照にして横長で行い、スクリプトで 120×120 に非等方縮小する。口の殻は 0.18 × 0.105（約 1.71:1）なので、同様に横長へ補正する。

## 生成時の条件（全コマ共通）

- 「生成」ではなく**コマ 0 を渡して「編集」**させる。目の形以外（毛色、位置、大きさ、頬、影の有無）は変えないと明示する
- 背景は透過ではなく**コマ 0 と同じ毛色で不透明**。縁のフェザリングはスクリプト側で付ける
- **ベースカラーのみ**。ハイライト・落ち影・光沢を描き込まない。ライティングは URP が付けるので、ベイクされたコマ 0 と質感が揃う
- 瞳の領域は必ず不透明に塗りつぶす。半透明だと元の目が透ける
- 文字・装飾・輪郭線の追加なし
- 半目（4）と閉眼（5）は**表情に依存しない中立な形**。全表情で共有され、ダンス切替の瞬間に見える顔になる
- 出力は正方形で最大解像度。縮小はスクリプトで行う

## 生成後にスクリプトで行うこと

- ChatGPT の出力は毛色が微妙にずれる。**目や口の領域だけを切り出してコマ 0 の上に合成**し、背景はコマ 0 のピクセルを使う。これで継ぎ目が消える
- 120×120 に縮小し、外周 4px を縁の複製で埋めて 128×128 にする
- アトラスに配置する（目 4×2、口 3×1。コマ番号は左上から右へ、次の行へ）

## 選別

1 コマにつき 2〜3 回生成し、元の目の位置から動いていないものを選ぶ。位置のずれは合成工程で多少吸収できるが、大きさが変わったものは使えない。

## ChatGPT への画像プロンプト

参照画像としてコマ 0（目は横に引き伸ばしたもの）を添付し、共通部分の後に各コマの行を差し替えて 1 枚ずつ生成する。

### 共通部分

```text
添付画像は 3D キャラクター（うさぎの赤ちゃん）の顔テクスチャの一部で、
両目の領域を切り出したものです。この画像を「編集」して、目の形だけを変えてください。

厳守すること:
- 目の形以外は一切変えない。毛の色・毛の質感・頬の色・画像内の目の位置と大きさ・
  画像の縦横比をそのまま維持する
- 背景は透過にせず、添付画像と同じ毛色で塗る
- ハイライト、落ち影、光沢、輪郭線を新たに描き込まない。フラットなベースカラーのみ
- 目の内側は完全に塗りつぶす（半透明・かすれ禁止）
- 文字や装飾を足さない
- 添付画像と同じ画風（トゥーン調、やわらかい塗り）
- 出力は添付と同じ構図・同じ切り出し範囲で、可能な最大解像度

変更内容:
```

### 目の各コマ

```text
[1 笑顔] 両目を上向きの弧（^ ^ の形）にした、うれしそうに笑って目を細めた目にする。
        瞳は見えなくてよい。弧の太さは元の目の輪郭線と同程度。
```

```text
[2 驚き] 両目を元より大きく丸く見開き、瞳を小さめにして白目の面積を増やす。
        目の中心位置は元と同じ。
```

```text
[3 得意げ] 上まぶたを下ろした半月形の目にする。目の下半分だけが見え、
          瞳は下寄りで自信ありげな表情。左右対称。
```

```text
[4 半目] まばたきの途中の目。上まぶたが目の高さの半分まで下りている。
        表情は付けず中立に。瞳の上半分がまぶたで隠れている。
```

```text
[5 閉眼] 完全に閉じた目。下向きのゆるい弧の線 1 本ずつだけにし、瞳もまつ毛も描かない。
        表情は付けず中立に。線の色は元の目の輪郭と同じ。
```

### 口の各コマ

参照はコマ 0 の口。共通部分の「両目」を「口」に読み替える。

```text
[1 半開き] 口を少し開ける。口の内側は暗めのピンク、歯や舌は描かない。
          口の幅は元と同じ、高さだけ 1.5 倍程度。
```

```text
[2 大きく開く] 歌っているように口を大きく丸く開ける。内側は暗めのピンクの単色、
             歯や舌は描かない。口の幅は元の 1.3 倍程度、高さは 2.5 倍程度。
```
