| サビ | 72〜74 | 足元アップ: 距離 2.0、ピッチ −20、FOV 18、Feet、Shake 0.2（clamp が実際に効く箇所） |# 拍駆動カメラディレクション 設計

## 目的

ダンスプレイヤーに、ミュージックビデオ風のカメラワークを入れる。カット割り・急接近・回り込み・パンチインを音楽の拍に同期させ、「固定 7 割 + 要所の急移動」「イージングで一気に動いて着地で止める」を実装で保証する。

## 方針

**カメラの姿勢は拍位置の純関数である。** ダンスと同じく時間源は `AudioSettings.dspTime` から得た拍だけ。`Time.deltaTime` / `Time.time` はランタイムに追加しない。同じ拍を渡せば同じ姿勢が返るため、EditMode で決定的にテストできる。

**Cinemachine は採用しない。** キャラは原点に固定されており（Bake Into Pose + `applyRootMotion=false`）Follow/Damping の価値がない。Cinemachine のブレンドは `Time.deltaTime` 駆動で時間源を増やす。手ブレは決定的ノイズを拍で引けば足りる。

**曲構造は分からない前提で 128 拍サイクルの譜面を持つ。** アプリは BPM と拍位置しか知らない。128 拍（120 BPM で 64 秒）を イントロ / A / B / サビ / アウトロ の擬似構造に割り、2 サイクル目以降はイントロを飛ばして A から回す。

## 構成

ランタイム（`Assets/Scripts/`、アセンブリ `BabyDance`）:

| 型 | 責務 |
| --- | --- |
| `CameraPose`（struct） | 1 フレームぶんの姿勢: `Distance`、`Yaw`（度）、`Pitch`（度）、`Fov`、`Roll`（度）、`Target`（`Hips` / `Head` / `Feet`）、`Shake`（0〜1）。純データ |
| `CameraScore`（static class） | `PoseAt(double beat)` を提供する純関数。譜面はコード内の配列で定義。カット、イージング移動、パンチイン、衝撃カットをすべてこの関数内で合成する。Unity の `Mathf` は使わず `System.Math` のみで書き、Unity 非依存を保つ |
| `ShotDirector`（MonoBehaviour） | Main Camera に付く。`Tick(double beat)` で `CameraScore.PoseAt` を取り、注視点のワールド座標（Animator の `HumanBodyBones` から取得）を中心に球面座標で位置を決め、`LookAt` + Roll + FOV を適用する。`Fixed` プロパティが真のときは譜面を無視し `CameraScore.FixedPose` を適用する |

配線:

- `DancePlayer.Update` は `driver.Tick(beat)` の直後に `director.Tick(beat)` を呼ぶ。Animator の更新後にボーンを読むための順序。停止中も毎フレーム `director.Tick(0)` を呼び、イントロの引き画に置く
- `DancePlayer` は `CameraAuto`（bool）と `ToggleCamera()` を公開し、`DanceUi` が「Camera: Auto」/「Camera: Fixed」ボタンを 1 つ追加する
- `SceneBuilder.Build` は Main Camera に `ShotDirector` を付け、`dancer`（Animator）と `player.director` を配線する

## 譜面

拍 `b` を入力とする。`b < 8` はイントロ。それ以外は `phraseBeat = 8 + ((b − 8) mod 128)` で 128 拍サイクルに写す。

各キューは `(開始拍, 終了拍, 開始姿勢, 終了姿勢, 移動拍数)`。移動拍数 0 はカット。移動拍数 > 0 はキュー開始から移動拍数だけ SmoothStep で開始姿勢→終了姿勢へ動き、以後は終了姿勢で完全静止する。

| イントロ | −∞〜4 | FOV 30、距離 4.2、ヨー 0、ピッチ 8、Hips。フィックス |

## 制約

- ピッチは −20 以上に clamp（アオリの下限、スカート裏対策）。距離は 1.0 以上
- Shake は正弦波の和による決定的ノイズ（Unity 非依存）を `beat × 3.1` で引き、ヨー・ピッチに ±0.6° × Shake、Roll に ±0.4° × Shake を加える。乱数は使わない
- 注視点ボーンの実座標は毎フレーム読む。急な頭の動きで画が跳ねないよう、`ShotDirector` は注視点を拍単位の指数平滑（時定数 0.25 拍）で追う。これが `ShotDirector` が持つ唯一の状態で、`Tick` に渡された拍差分だけで進める
- 該当ボーンが無い（Humanoid でない）場合は例外で止める。フォールバックは持たない
- DoF・ポストプロセスは追加しない

## テスト（`Assets/Tests/EditMode/CameraScoreTests.cs`）

各テストは「壊した実装で落ちるか」を基準に選ぶ。

1. **カット境界**: 拍 29.99 と 30.01 で FOV が 26 → 10 に不連続。30.0〜31.99 の間は一定
2. **着地の静止**: 拍 74〜74.5 の間 FOV が単調減少し、74.5 以降 80 直前まで姿勢が bit 一致で不変
3. **イージング終端一致**: 拍 8 の姿勢は距離 3.2（イントロ寄り終端）ではなく A の開始姿勢。拍 7.999 は距離 3.2
4. **clamp**: 拍 −4〜140 を 1/16 拍刻みで走査し、ピッチ ≥ −20、距離 ≥ 1.0、FOV が [10, 55]
5. **パンチイン**: 拍 84.0 直後の FOV が 84.5 より小さく、85.0 直後で再び小さい（1 拍周期）。拍 40〜56 ではパンチインが無い
6. **衝撃カット**: 拍 96.05 は距離 1.4、96.2 は 2.6
7. **サイクル**: 拍 136 と拍 8 の姿勢が一致。拍 136 はイントロ（距離 4.2）ではない。`PoseAt(50)` を 2 回呼んで一致
8. **Shake の決定性と有無**: 拍 50 の 2 回呼び出しが一致。拍 20（Shake 0）はノイズ項が無く整数角度のまま

`ShotDirector` の Unity 依存部分（ボーン取得・LookAt）は PlayMode テストで 1 本: Animator 無しの GameObject に対して `Tick` が例外を投げる。ボーン位置追従は目視。
